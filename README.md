# Kuunneltava YO-valmentaja

Kuunneltava YO-valmentaja on audio-first-opiskelukonsepti historian ylioppilaskokeeseen valmistautumiseen.

Tavoitteena ei ole tehdä oppikirjoista äänikirjoja tai tavallisia podcasteja. Tavoitteena on rakentaa oppimisjaksoja, jotka auttavat opiskelijaa ymmärtämään historiallisia kokonaisuuksia, syy–seuraussuhteita, käsitteitä, aineistoja ja YO-kokeessa vaadittavaa argumentointia.

## Nykyinen tavoite

Ensimmäinen pilotti rajataan tarkoituksella pieneksi:

- yksi historian aihe
- noin 15–20 minuutin oppimisjakso
- yksi kertojaääni
- ennakkotesti
- aktiivisia kysymyksiä
- jälkitesti
- käyttäjäpalaute

Projektia ei laajenneta muihin aiheisiin tai oppiaineisiin ennen kuin ensimmäisen jakson oppimishyöty on testattu.

## Dokumenttien ensisijaisuus

Jos tiedot ovat ristiriidassa, käytetään seuraavaa järjestystä:

1. voimassa olevat YTL:n ja OPH:n viralliset lähteet
2. projektin kanoniset pedagogiikkadokumentit
3. hyväksytyt päätösdokumentit
4. aktiivisen jakson dokumentit
5. keskustelut ja työmuistiinpanot

Keskustelu ei yksinään ole projektin kanoninen muisti. Hyväksytyt lähteet, periaatteet ja päätökset tallennetaan repositoryyn.
