# Pedagogiikka

**Tila:** Kanoninen  
**Viimeksi tarkistettu:** 31.7.2026

Tämä hakemisto sisältää projektin pitkäikäiset pedagogiset periaatteet ja virallisista lähteistä johdetut tulkinnat.

## Sisältö

- [`historian-koevastauksen-arviointi.md`](historian-koevastauksen-arviointi.md) — miten historian koevastauksia arvioidaan ja mitä laudatur-tasoa tavoittelevan vastauksen tulee käytännössä osoittaa

## Mitä tänne tallennetaan

- historian oppimisen ja historiallisen ajattelun periaatteet
- kuunneltavan oppimisjakson pedagogiset laatukriteerit
- aktiivisen oppimisen periaatteet
- ennakko- ja jälkitestien suunnitteluperiaatteet
- virallisista YTL- ja OPH-lähteistä johdetut projektin tulkinnat

## Mitä tänne ei tallenneta

- pelkkiä ulkoisia lähdeluetteloita
- yhden oppimisjakson käsikirjoituksia tai lähdemuistioita
- keskeneräisiä keskustelumuistiinpanoja
- teknisiä toteutusratkaisuja

## Tiedon luokittelu

Pedagogiikkadokumentissa pitää tehdä näkyväksi, onko väite:

1. **Varmistettu lähdetieto** — suoraan YTL:n, OPH:n tai muun luotettavan lähteen perusteella
2. **Projektin tulkinta** — lähteistä johdettu käytännön pedagoginen ratkaisu
3. **Testaamaton hypoteesi** — oletus, jonka toimivuus pitää todentaa pilotissa

## Hyväksymisperiaate

Pedagoginen periaate voidaan merkitä kanoniseksi, kun:

- sen lähdepohja on kuvattu
- se parantaa todennäköisesti oppimista tai kokeessa vaadittavaa osaamista
- se on riittävän yleinen koskemaan useampaa kuin yhtä yksittäistä käsikirjoitusta
- sen suhde projektin ensimmäiseen pilottiin on selvä

Pilotin käyttäjätesti voi myöhemmin vahvistaa, muuttaa tai kumota projektin omia tulkintoja ja hypoteeseja.
