# Lähteet

**Tila:** Kanoninen  
**Viimeksi tarkistettu:** 31.7.2026

Tämä hakemisto sisältää projektin ulkoiset totuuden lähteet.

## Sisältö

- [`historian-yo-koe.md`](historian-yo-koe.md) — historian ylioppilaskokeen rakenne, arviointi, opetussuunnitelma ja virallisten lähteiden tarkat URL-osoitteet

## Mitä tänne tallennetaan

- YTL:n määräykset ja ohjeet
- OPH:n opetussuunnitelmat ja osaamistavoitteet
- aiemmat ylioppilaskokeet ja hyvän vastauksen piirteet
- luotettavat historian tutkimus- ja taustalähteet, kun ne koskevat koko projektia
- lähteen käyttötarkoitus, tarkka URL ja viimeinen tarkistuspäivä

## Mitä tänne ei tallenneta

- projektin omia pedagogisia tulkintoja
- oppimisjaksojen käsikirjoituksia
- yhden jakson yksityiskohtaista faktamuistiota
- keskustelujen yhteenvetoja

## Lähteiden ensisijaisuus

1. voimassa olevat YTL:n määräykset ja arviointiohjeet
2. voimassa oleva OPH:n lukion opetussuunnitelma
3. YTL:n aiemmat kokeet ja hyvän vastauksen piirteet
4. vertaisarvioitu tutkimus ja yliopistojen aineistot
5. luotettavat oppikirjat, arkistot ja museot

## Päivityssääntö

Kun lähde muuttuu:

1. päivitä URL tai lähdeviite kanoniseen lähdedokumenttiin
2. merkitse uusi tarkistuspäivä
3. arvioi, vaikuttaako muutos `pedagogy/`-hakemiston johtopäätöksiin
4. älä luo vanhasta dokumentista rinnakkaista versiota
