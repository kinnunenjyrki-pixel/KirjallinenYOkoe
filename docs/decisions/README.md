# Päätökset

**Tila:** Kanoninen  
**Viimeksi tarkistettu:** 31.7.2026

Tämä hakemisto sisältää projektin merkittävät ja pitkäikäiset päätökset.

Päätösdokumentti luodaan vain silloin, kun päätöksen unohtaminen voisi johtaa projektin suunnan muuttumiseen, aiemman keskustelun tarpeettomaan toistamiseen tai pilotin rajauksen laajenemiseen.

## Mitä tänne tallennetaan

- merkittävä päätös
- päätöksen perustelut
- tärkeimmät vaihtoehdot, jotka rajattiin pois
- päätöksen vaikutukset projektiin
- ehto tai ajankohta, jolloin päätös arvioidaan uudelleen

## Mitä tänne ei tallenneta

- päivittäistä työtilannetta
- pieniä sanamuoto- tai käsikirjoitusratkaisuja
- lähdetietoja
- keskusteluja sellaisinaan
- toteuttamattomia ideoita ilman päätöstä

## Tiedoston nimeäminen

Päätösdokumentit nimetään juoksevasti:

```text
DEC-001-aiheen-nimi.md
DEC-002-aiheen-nimi.md
```

## Päätösdokumentin pohja

```markdown
# DEC-001: Päätöksen nimi

**Tila:** Hyväksytty
**Päiväys:** PP.KK.VVVV

## Konteksti

Mikä kysymys tai ongelma vaati päätöksen?

## Päätös

Mitä päätettiin?

## Perustelut

Miksi tämä ratkaisu valittiin?

## Rajauksen ulkopuolella

Mitä ei toteuteta tai ratkaista tällä päätöksellä?

## Uudelleenarviointi

Milloin tai millä ehdolla päätös avataan uudelleen?
```

## Nykytila

Ensimmäisiä erillisiä päätösdokumentteja ei vielä ole luotu. Ne lisätään vasta, kun päätös on riittävän merkittävä ja hyväksytty kanoniseksi.
